# About Quiz Arena Backend

Quiz Arena Backend is the API and service layer for the Quiz Arena mobile trivia product. It handles application data, authentication, media/storage, scheduled jobs, AI-assisted features, push-related workflows, monitoring, and real-time Socket.IO communication.

For setup and execution, see [`run_instruction.md`](./run_instruction.md). For the broader project overview, see [`README.md`](./README.md).
